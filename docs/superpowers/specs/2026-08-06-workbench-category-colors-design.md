# 虞律团队 AI 工作台分类色阶与注意提示设计

## 目标

在不改变工作台现有克制风格的前提下，解决两项首页 UI 问题：侧栏单句提示误用“01”章节编号，以及五类工具缺少直观但不过度的视觉区分。

## 已确认设计

- 将侧栏提示中的“01”改为文字标题“注意”。
- 保留现有灰底提示块和提示正文：工具结果仅供工作辅助，关键结论须由经办律师复核。
- 五类工具采用同一墨绿/鼠尾草绿色系的五档色阶：
  - 数据安全：最深墨绿 `#29443a`
  - 基础工作：深灰绿 `#3f5e52`
  - 文书制作：标准鼠尾草绿 `#587667`
  - 专业法律分析：浅灰绿 `#718d7f`
  - Anthropic Legal：柔和雾绿 `#8da397`
- 分类色只用于侧栏分类名称、数量和工具卡片顶部细线；卡片主体继续使用白色。
- “全部工具”的当前选中状态继续使用现有深墨绿底色，不引入新的强调色。
- 色彩不是唯一的分类信息：分类名称文字继续保留，保证可访问性。

## 实施边界

- 首页分类按钮和工具卡片增加可供样式定位的分类属性。
- 不修改工具数据、分类数量、搜索筛选、详情页、行动按钮或发布地址。
- 保持桌面端与移动端现有布局和交互方式。

## 验收标准

- 首页侧栏提示显示“注意”，不再显示“01”。
- 五个分类按钮和对应工具卡片都带有相同的分类标识属性。
- 五个分类使用同一绿色系的五档色阶，卡片仅出现顶部细线，白色主体保持不变。
- 现有页面测试、工具注册表测试、构建与代码检查全部通过。
